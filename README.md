# 🏥 Doctor AI Studio (Multilingual EN/GU + Vercel Cloud Live Deployment)

- **Multilingual Support**: Instant 1-click toggle between **English (US)** and **Gujarati (GU)** in the left sidebar and settings.
- **Vercel Cloud Deployment Ready**: Includes `vercel.json` and `api/index.py` for free serverless live hosting.
- **WhatsApp AI Chatbot**: Interactive WhatsApp Chatbot that handles bookings, checks slots, and notifies doctor (`+91 9099555744`).
- **Gujarati AI Voice Agent**: Interactive voice calling agent with free browser microphone simulator.

---

## 🌐 Deploy Live to Vercel (1-Click Cloud Hosting)

1. Push this project folder to your **GitHub** repository.
2. Go to **[Vercel.com](https://vercel.com)** and sign in.
3. Click **"Add New Project"** and select your GitHub repository.
4. Click **Deploy**. Vercel will automatically read `vercel.json` and deploy your FastAPI Doctor Dashboard live on the web!

---

## 💻 Localhost Quick Launch

- **Windows**: Run `run_dashboard.bat`
- **Linux/Mac**: Run `./run_dashboard.sh`
- Open `http://localhost:8080` in your browser.
